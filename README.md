# 🛒 Shopping Cart Program (Java)

A simple Java console program that calculates the total price for items based on **price** and **quantity**.

---

## 💡 What I Learned
- How to get **user input** using `Scanner`
- How to handle **Strings, numbers, and arithmetic operations**
- How to calculate **total price** using variables
- How to display results using **System.out.println()**
- Basic project structure for a console-based Java program

---

## ▶ How to Use
1. Run the program (`Main.java`) in IntelliJ or terminal
2. Enter the **item name**
3. Enter the **price per item**
4. Enter the **quantity**
5. The program will display the **total price**
